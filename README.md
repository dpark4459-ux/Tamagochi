# 몽실이의 산책일기 — PWA 프로토타입

웰시코기 픽셀아트 펫과 산책 습관을 키우는 한국어 모바일 웹앱입니다.

## 들어 있는 기능
- 실제 픽셀아트 웰시코기 캐릭터 프레임 8종
- 경험치와 5단계 성장
- 현관문 밖으로 나가기 보상
- 산책 타이머 및 완료 보상 (5분 미만도 기록되며 XP는 0)
- 매일 날짜에 따라 바뀌는 격려 문구 및 메시지 다시 보기
- 식후 산책 체크
- 직접 선택하는 날씨별 미션
- 경험치로 해금하는 액세서리
- 누적 통계와 최근 산책 기록
- 브라우저 로컬 저장소 및 오프라인 캐시
- PWA manifest / 서비스 워커 / 홈 화면 아이콘

## 휴대폰에서 사용하기
PWA는 `file://`로 직접 여는 방식이 아니라 HTTPS로 제공되어야 설치 기능과 서비스 워커가 작동합니다.

### 가장 쉬운 배포: GitHub Pages
1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더의 파일과 `assets` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch → `main` / `/root`를 선택하고 저장합니다.
4. 발급된 HTTPS 주소를 Android Chrome에서 엽니다.
5. Chrome 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.

### Netlify Drop
폴더를 ZIP으로 압축 해제한 뒤 Netlify의 수동 배포 화면에 폴더를 드래그하면 HTTPS 주소를 받을 수 있습니다. 해당 주소를 Android Chrome에서 열어 설치하세요.

## 데이터 및 제한 사항
- 산책 기록은 해당 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기/브라우저 사용 시 기록이 공유되지 않습니다.
- 현재 날씨는 사용자가 직접 선택합니다. 실시간 날씨 API는 연결되어 있지 않습니다.
- 알림 버튼은 브라우저 알림 권한을 요청합니다. 반복 알림 예약 기능은 아직 구현되어 있지 않습니다.
- 타이머가 실행 중인 상태로 브라우저를 닫으면 산책 완료 기록은 저장되지 않습니다.
- 혈당 측정이나 의료 모니터링 기능은 없습니다. 식후 산책 여부만 기록합니다.

## 개발 메모
순수 HTML/CSS/JavaScript로 구성되어 별도 빌드 도구가 필요하지 않습니다. HTTPS 정적 호스팅에 업로드하면 됩니다.
